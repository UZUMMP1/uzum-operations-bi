# Public Portfolio Privacy Checklist

Before every public upload, confirm that the repository contains none of the following:

- `.env` files or real database URLs
- API keys, tokens, passwords, certificates, or cookies
- Real order numbers, customer data, employee emails, or internal contacts
- Real SKU-level sales, inventory, targets, or pricing data
- Raw company exports, production databases, or service logs
- Internal deployment, ownership, or handover instructions

Use fictional data, anonymized screenshots, and placeholder credentials only.
