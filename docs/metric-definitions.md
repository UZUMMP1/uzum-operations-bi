# Metric Definitions

| Metric | Portfolio Definition |
|---|---|
| SO | Net sold units after the applicable cancellation and return logic |
| GMV | Sum of recognized merchandise value for the selected period |
| ASP | GMV divided by net sold units when SO is greater than zero |
| UV | Available product-page visitor or traffic proxy |
| CVR | Order units divided by the available visitor measure |
| Inventory | Latest available sellable-stock snapshot |
| DOS | Latest inventory divided by recent average daily sales |
| Return Rate | Returned units divided by gross sold units |

The public sample is illustrative. Production definitions may depend on platform export fields and should be validated with the business owner.
