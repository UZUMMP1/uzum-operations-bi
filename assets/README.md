# Screenshot Checklist

Add only anonymized or Mock-Data screenshots here. Recommended filenames:

- `dashboard-overview.png`
- `category-performance.png`
- `inventory-monitoring.png`
- `traffic-conversion.png`
- `returns-cancellations.png`

Before uploading, remove real SKU codes, order numbers, employee names, email addresses, exact internal targets, database information, and confidential sales or inventory values.
