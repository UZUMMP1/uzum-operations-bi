# Public Source Extract

This directory contains a portfolio-safe extract of the original private application.

Included:

- FastAPI application code and automated tests
- React / TypeScript dashboard source
- Dependency manifests and Docker build definition

Excluded:

- Production databases and raw exports
- `.env` files and service credentials
- Local virtual environments, `node_modules`, caches, and build artifacts
- Internal deployment handover documents
- Production migration sessions and logs

Use only fictional data and a local development database when running this extract.
